Photojournal Home Photojournal Search Latest Content Galleries Feedback RSS About 1 Min Read Curiosity Spots Drifting Twilight Clouds PIA26805 Credits: NASA/JPL-Caltech Image Addition Date: 11/20/2026 Downloads Curiosity Spots Drifting Twilight Clouds GIF (2.59 MB) Description NASA’s Curiosity Mars rover captured these drifting clouds on Oct. 31, 2026, the 5,061st Martian day, or sol, of the mission. The rover uses its navigation cameras to capture post-sunset clouds, called twilight clouds, which appear for only a short time each fall over Gale Crater, which it has been exploring for more than 14 years. Curiosity was built by NASA’s Jet Propulsion Laboratory, which is managed by Caltech in Pasadena, California. JPL leads the mission on behalf of NASA’s Science Mission Directorate in Washington as part of NASA’s Mars Exploration Program portfolio.
